## Standalone Follow-Up Posts

### Day 3 — Post 7: governed PDF intake

Attach `assets/social/x/governed-pdf-research-1200x628.png`.

> PDF support is deliberately governed. Markdown and text work immediately. PDF extraction is optional, pinned, native-text only, and never auto-installed. Core asks permission first. Scanned, empty, encrypted, and unavailable states remain explicit.

### Day 5 — Post 8: explicit PDF statuses

Attach `assets/social/x/pdf-intake-status-terminal-1200x628.png`.

> PDF intake should never blur unsupported states.
>
> supported → process native text
> dependency_unavailable → ask before install
> no_extractable_text → preserve the empty result
> encrypted → stop without requesting passwords
>
> Exact source bytes remain evidence in every case.

### Day 8 — Post 9: testing lifecycle

Attach `assets/social/x/test-lifecycle-1200x628.png`.

> Testing follows the work: focused tests while editing, cached failures for triage, Git-affected selection for changed paths, then bounded regression.
>
> Only the final candidate gets the full parallel-safe phase plus exclusive serial tests.

### Day 10 — Post 10: executable test profiles

Attach `assets/social/x/test-runner-terminal-1200x628.png`.

> Five pytest profiles. One lifecycle.
>
> focused → current surface
> failed → cached failures
> affected → Git impact map
> broad → bounded regression
> full → parallel-safe + serial isolation
>
> Terra debugs narrowly. Luna verifies the final candidate once.

### Day 12 — Post 11: portable continuity

Attach `assets/social/x/portable-continuity-1200x628.png`.

> Continuity lives in Git, not model memory. A fresh task, another device, or a new employee can rehydrate the same owner from bounded transcripts, receipts, decisions, and current evidence—without treating an old conversation as present authority.

### Day 15 — Post 12: adoption invitation

Use no image so the repository link receives the final call to action.

> The bootstrap is meant to be copied, renamed, and filled with your own research. Start with Core. Add owners only when real boundaries emerge. Run the conformance suite. Challenge the design, fork it, and tell me which safeguards are useful—or too opinionated. [REPO_URL]
