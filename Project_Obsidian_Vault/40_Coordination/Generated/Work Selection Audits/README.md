## Purpose

This directory contains source-only audit records written by
`agent_work_selection_audit.py` for substantial next-step selections.

## Contents

Each content-addressed Markdown file records a frozen evidence baseline,
candidate, ownership, dependencies, and advisory disposition. Records remain
non-authorizing even when their checks pass.

## Change Discipline

Do not hand-edit generated audits. Create a new audit when the evidence
baseline changes, preserve earlier records, and update navigation through the
vault maintainer.
