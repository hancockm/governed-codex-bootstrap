## Common Agreement

- Questions, attachments, research, critique, and hypothetical architecture
  provide context; they do not independently authorize implementation.
- An accepted plan authorizes only its recorded scope and owners.
- Repository evidence outranks confident recollection.
- Ownership is strict. Route another owner's need through A2A rather than
  editing that owner's semantics, UI, doctrine, continuity, or source.
- Recent implementation may satisfy, narrow, reorder, or invalidate a future
  step, so assumptions must be questioned before sequencing.
- Preserve distinctions between source and derived state, diagnostics and
  authority, passive receipts and executed decisions, proposals and truth.
- Do not create local substitutes for shared public contracts to bypass a
  boundary.
- Direct disagreement and explicit uncertainty are preferable to agreeable
  overstatement or silent gap filling.
- Completion includes proportionate verification, Git/worktree inspection,
  branch reconciliation, and honest residual-failure reporting.
- Concurrent or pre-existing work remains untouched unless explicitly added
  to the current task.

## All Remaining Disagreements

None about this shared collaboration protocol. Project, feature, or owner-
specific disagreements remain in their assigned records.

## Critical Weak Points

- A rich discussion can be mistaken for implementation authority.
- An agent can identify a cross-owner dependency correctly but edit the wrong
  owner's files instead of requesting the boundary.
- Historical continuity can create false confidence after canonical or runtime
  state changes.
- Passing focused tests can be overstated as complete delivery.
- Dirty worktrees make unrelated changes easy to absorb or discard.

## Convergence Move

Apply root [AGENTS.md](../../../AGENTS.md) and the active role profile. When these rules expose an
owner dependency, publish a boundary request. When they expose a canonical/
runtime mismatch, report it and route correction through the responsible
owner.
