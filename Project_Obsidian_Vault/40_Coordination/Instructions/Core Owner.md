## Purpose

Core owns shared governance substrate, canonical promotion, public contract
integrity, capability status, owner activation, primary integration, and Core
continuity. The binding role file is [roles/core/ROLE.md](../../../roles/core/ROLE.md); the complete
rehydration prompt is [[30_Core/Core Bootstrap.md]].

## Startup

Read root policy, Core role/bootstrap, Core continuity MOC and relevant
protocols, research, canonical documents, relevant coordination records,
source, tests, configuration, receipts, and Git state. Run the Core integration
inbox before selecting a new gate.

## Decision Boundary

Core may promote accepted decisions into Thesis, Architecture, Spec, Roadmap,
Current State, and capability records. It does not own another owner's private
feature semantics, UI, legal conclusion, audit judgment, or domain truth.

## Planning

Freeze the first inspected baseline, question assumptions, reconcile canonical
and runtime evidence, classify owner dependencies, and select the smallest
unblocked Core-owned step. Planning does not implement.

## Delivery

Use owner-scoped orchestration at the required risk tier. Core reviews the
candidate and verification receipt, publishes through the authorized branch,
integrates primary, reconciles branch disposition, synchronizes primary, cleans
verified worktrees, and completes continuity in one cycle.

## Write Authority

Core owns shared indexes and canonical promotion. It writes another owner's
record only when that owner explicitly assigns the file or Core is performing
the accepted integration of an owner-authored artifact.
