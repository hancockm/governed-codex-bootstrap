Continuity closeout preserves bounded, attributable history without creating a
second canonical system.

## Export

Use the exact session source and the registered Core label, schemas, thread ID,
transcript directory, and vault target. Dry-run the exporter, inspect the
source-prefix and selected-record evidence, then apply. Never reconstruct a
missing source from memory or summaries.

## Maintain

1. Link the transcript root and compact orchestration receipts from this MOC.
2. Synchronize navigation for the registered vault scope.
3. Refresh the transcript manifest against post-navigation bytes.
4. Require an idempotent dry manifest refresh.
5. Run vault checks and inspect the exact Git diff.

Generated transcript records, breadcrumb blocks, and output inventories are
tool-owned. Do not hand-edit them. One thread belongs to one continuity owner;
cross-owner context moves through A2A links.

## Close

Stage only owned continuity changes, commit and publish them, prove terminal
branch reconciliation and primary synchronization, remove verified-clean
temporary worktrees, and archive accepted subordinate tasks only after their
receipts and delivery evidence are durable.
