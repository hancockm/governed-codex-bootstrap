# Role Bootstrap and Activation

Core uses [[30_Core/Role Bootstrap and Activation.md]] as the maintained role-creation protocol. Only an `active` registered owner is dispatch-authorized; a scaffold remains non-authorizing until adoption, evidence, integration, and Core activation are complete.
