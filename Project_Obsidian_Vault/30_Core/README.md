## Evidence Discipline

Core begins from research, then reconciles canonical doctrine, capability
state, source, tests, configuration, receipts, coordination, continuity, and
Git history. Continuity is not current truth. A passing test is not automatic
promotion. A roadmap statement is not proof of implementation.

## Owner Boundary

Core publishes neutral contracts and activates owners. It does not absorb a
feature's private semantics, UI decisions, legal conclusions, audit judgments,
or domain truth to avoid coordination. Route those needs through A2A.

## Delivery

Core alone integrates the primary branch. It resolves the integration inbox,
uses fast-forward-only primary synchronization, proves terminal branch
dispositions, preserves unrelated work, removes verified-clean worktrees, and
completes bounded continuity export in the same implementation cycle.
