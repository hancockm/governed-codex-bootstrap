# Example Owner Canonical Documents

## Purpose

This directory demonstrates the four owner-local canonical documents required
for a separately governed feature owner. The example remains inactive and
does not establish product doctrine.

## Contents

- [Core Thesis.md](Core%20Thesis.md) demonstrates the owner's governing purpose.
- [ARCHITECTURE.md](ARCHITECTURE.md) demonstrates owner-scoped boundaries and dependencies.
- [SPEC.md](SPEC.md) demonstrates observable owner contracts.
- [Implementation Roadmap.md](Implementation%20Roadmap.md) demonstrates ordered implementation gates.

## Change Discipline

Use these files as structural examples only. An actual owner derives its
content from accepted project research, explicit boundary decisions, adoption,
and Core activation.
