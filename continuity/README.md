# Continuity Sources

## Purpose

This directory provides non-vault storage anchors for owner continuity inputs
and export destinations. Continuity preserves history but is never canonical
authority.

## Contents

- `core/` contains the initially active owner's transcript-export boundary.
- Future owner roots are created only through the activation workflow.

The maintained narrative continuity MOC lives under
`Project_Obsidian_Vault/30_Core/Continuity/`.

## Change Discipline

One task belongs to one owner archive. Never copy another owner's transcript,
hand-edit generated exports, or reconstruct unavailable source from memory.
