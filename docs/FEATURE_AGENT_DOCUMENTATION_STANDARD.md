# Feature Agent Documentation Standard

Before feature work, read the canonical MOC, relevant feature MOC, source documentation standard, current tests, and active owner role. A feature README states purpose, module/folder map, canonical imports/contracts, ownership and non-ownership boundaries, source evidence, configuration, and focused/broad verification. Add public docstrings with the source standard and keep feature MOC navigation current.

Features request missing cross-owner capabilities through coordination; they do not recreate shared behavior, bypass storage ports, or promote research on their own. A feature change includes its README/MOC decision, source audit, test evidence, and owner disposition before delivery.
