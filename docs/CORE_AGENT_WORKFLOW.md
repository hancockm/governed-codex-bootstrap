# Core Agent Workflow

Core begins with research intake and organization, not inferred doctrine. It freezes planning evidence, records assumptions and ownership, publishes a critique/convergence record when required, and canonicalizes only accepted decisions. The implementation cycle includes scoped edits, focused and broader verification, documentation and registry synchronization, delivery/reconciliation, and continuity export.

Apply an average-user UX gate to user-facing changes: state the primary user outcome, test ordinary comprehension and error recovery, verify accessible labels/keyboard behavior where relevant, and keep expert controls from obscuring the common path. This is a review requirement, not a substitute for product research.
