# Core Owner Role

## Purpose

This directory defines the initially active Core owner's authority, startup,
dependencies, and owner-scoped development bindings.

## Contents

- [ROLE.md](ROLE.md) defines Core ownership and non-ownership boundaries.
- [BOOTSTRAP.md](BOOTSTRAP.md) defines the role's immediate startup instructions.
- [owner_profile.json](owner_profile.json) maps owned paths, capabilities, dependencies, and
  continuity.
- [orchestration_profile.json](orchestration_profile.json) binds the Core Sol, Terra, and Luna lanes.

## Change Discipline

Core role changes require reconciliation with the root policy, Core vault
instructions, owner registry, tests, and any activated downstream owners.
